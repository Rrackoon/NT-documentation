## Самый важный сценарий MVP

Критический для MVP сценарий - UC-03, добавление записи в дневник питания:

1. Пользователь открывает дневник
2. Выбирает дату и тип приема пищи
3. Ищет продукт или создает пользовательское блюдо
4. Указывает количество
5. Система рассчитывает КБЖУ
6. Пользователь сохраняет запись
7. Система обновляет дневной баланс

## Sequence diagram для добавления приема пищи

```plantuml Meal Creation Sequence
@startuml
actor User
participant "Mobile App" as App
participant "Backend API" as Api
database "Database" as Db

User -> App: Ввод данных о приеме пищи
App -> Api: POST /meals
Api -> Api: Валидация данных

alt Ошибка валидации
  Api --> App: 400 Validation Error
  App --> User: Отобразить ошибку
else Данные корректны
  Api -> Api: Расчет калорий и БЖУ
  alt Ошибка расчета
    Api --> App: 422 Calculation Error
    App --> User: Отобразить ошибку
  else Успешный расчет
    Api -> Db: Сохранить Meal и MealItems
    Db --> Api: OK
    Api --> App: 201 Created + totals
    App --> User: Показать обновленный дневник
  end
end
@enduml
```

## Альтернативные потоки

- продукт не найден в базе, поэтому пользователь создает собственный
- количество некорректно, поэтому система запрашивает повторный ввод
- запись уже существует и пользователь ее редактирует
- пользователь удаляет запись, а система пересчитывает дневные итоги

# BPMN и decision table

## Основной процесс

Текущий BPMN-артефакт описывает поток добавления нового приема пищи:

1. Пользователь выбирает добавление записи
2. Система выполняет поиск продукта или пользователь создает собственное блюдо
3. Пользователь указывает количество
4. Сервис валидирует калорийность
5. Пользователь получает статус `OK`, `Warning` или `Recommendation`
6. После подтверждения запись сохраняется
7. Система пересчитывает дневной баланс и обновляет экран дневника

## Правила проверки калорийности

| Калории в текущем приеме | Суммарные калории | Цель пользователя | Результат | Уровень | Интерпретация |
| --- | --- | --- | --- | --- | --- |
| - | `> dailyGoal * 1.2` | - | Warning | High | Суточная норма значительно превышена |
| - | `> dailyGoal and <= dailyGoal * 1.2` | - | Warning | Medium | Есть превышение суточной нормы |
| - | `>= dailyGoal * 0.9 and <= dailyGoal` | - | Recommendation | Low | Пользователь близок к лимиту |
| - | `>= dailyGoal * 0.8 and < dailyGoal * 0.9` | - | Recommendation | Medium | Стоит уменьшить порцию |
| - | `< dailyGoal * 0.8` | - | OK | None | Все в порядке |
